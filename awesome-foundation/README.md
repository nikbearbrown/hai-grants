# The Awesome Foundation

## Boston community microgrant

**Status:** Logged for screening; nothing submitted. The Boston chapter advertises **$1,000 monthly microgrants** and has a live application form. Neither public page lists a fixed submission date or the next award decision. The Boston chapter’s posted award history ends in 2022, so the advertised cadence is not confirmed in practice. Individuals, groups, and organizations, including nonprofits, can apply.

**Possible project:** Run one free public workshop in Greater Boston where participants make a short AI-assisted story or song from a local topic and learn to check the output before sharing it. A venue partner, a concrete audience, and a short budget for accessibility, materials, and delivery would make the request specific. Ask for a defined event rather than unrestricted operating support. An alternative is a paper-first session on checking AI claims. The St. Paul chapter funded [AI for Beginners](https://www.awesomefoundation.org/en/projects/428675-ai-for-beginners), a free public AI literacy workshop series, in May 2026. That is a precedent in a different chapter. No venue or dates are committed.

**Application prep:** The public form asks for a project title, a description (2,000 characters), use of funds (500), and a short applicant description (500). Include the proposed event date and when funds are needed in the description.
