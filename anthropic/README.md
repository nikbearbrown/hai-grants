# Anthropic

## Claude Corps: host a fellow

**Status:** Screening. The host FAQ describes rolling applications for placements beginning March and August 2027 and does not publish a host cutoff for either. The linked Typeform resolves to the host application title, but it did not expose the questionnaire or confirm intake for either cohort. Fellow applicant deadlines are separate.

**Eligibility and cost:** U.S. 501(c)(3) nonprofit with Claude for Nonprofits Team or Enterprise, a senior sponsor, and a named day-to-day supervisor. Fully remote applicants can be considered for 2027. Universities, colleges, and school districts are outside the host program's current scope. Verified nonprofits can get Team for $8 per seat per month with a two-seat minimum ($16/month before applicable taxes).

**Support:** Up to four full-time placements for 12 months. CodePath employs the fellows; salary and benefits are funded. Hosts receive a one-time $10,000 implementation grant per organization and up to $2,500 in Claude access and credits per fellow. The host provides equipment, approved system access, supervision, basic reporting, and a continuity plan. The program covers travel and lodging for two in-person convenings for fellows and a host representative.

**Potential fit:** Start with one fellow building and evaluating a source-checked workforce-resource workflow for Humanitarians AI. Name the supervisor, schedule time for review, and define how staff will maintain it. This is separate from funding or converting existing Humanitarians AI volunteer roles. Verify intake and the organization's plan status before paying for any subscription.
