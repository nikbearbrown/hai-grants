# Data visualization skill

Give [SKILL.md](SKILL.md) to Claude, Codex, or another coding agent. You can ask it to recommend charts, build one in your chosen tool, or audit an existing figure.

> Use the data visualization skill. I need a chart from this table for a public report. Recommend two options, pick the clearer one, and build it as an editable Excel chart. Preserve missing and suppressed entries. Show me how you checked the numbers.

- [Chart catalogue](chart-catalogue.md): choose by question and data shape, not by tool or novelty.
- [Tool playbooks](tool-playbooks.md): Figma, Power BI, Python, D3, Excel and PowerPoint, plus a route for other tools.
- [Worked example](examples/): synthetic fixture and a reproducible source-value check.

The skill directs an agent; it does not install integrations, grant write access, or guarantee that every runtime can author native files. The example verifies data calculations, not renderer or connector compatibility.
